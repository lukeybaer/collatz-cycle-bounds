## Full m=100 repeat

The full-run inputs and output use the label `reference-m100-full-20261002` under `results/`. Completion and comparison are recorded in:

- `wide-m100-fourth-power-J38-grafted-release-full-reference-audit.json`: exact seven-counter comparison and node normalization.
- `cycle-exclusion-m100-fourth-power-grafted-audit.json`: a fresh end-to-end audit including that comparison and its dependencies.

The full repeat completed all 956 jobs with zero survivors on 3 October 2026 UTC. Reproduce its receipts with `python scripts/verify_revision.py --m100`. This reruns journal coverage, generator and partition checks in a temporary manifest-only checkout before rebuilding and comparing both receipts. It does not repeat the full multi-billion-node search; that command is documented in `paper/VERIFICATION-REPORT.md`.

A result file must match the reference journal's finish entry, and its configuration and kernel hashes must match the preserved sources. An optimized Python run that disables assertions is rejected. The old end-to-end receipt in `results/` remains unchanged; use the revision receipt here when assessing the completed repeat.

`status: passed` means the named check passed. The mathematical reduction, external theorems, and priority still require independent review.
